This module keeps AI security mapping at an orientation level. The curated resources introduce MITRE ATLAS as a vocabulary for describing adversary behavior and security observations in AI systems. Your artifact is a short mapping note that connects one AI system concern to relevant ATLAS concepts, then names what evidence or control would be needed for review. Use the module responsibly by treating mappings as a shared language, not as a checklist that proves safety. Avoid overclaiming coverage when a system has not been tested or reviewed. The value of mapping is clearer communication between builders, security teams, and reviewers.
