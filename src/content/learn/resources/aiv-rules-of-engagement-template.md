Use this template before any offensive AI security lab or assessment.

Required fields:

- Scope
- Authorized target
- Allowed actions
- Disallowed actions
- Data classes
- Stop conditions
- Reporting path
- Debrief expectation

The template is complete only when a reviewer can tell what is authorized, what is out of scope, when work stops, and how findings will be reported.
